⚡ REST API Endpoints & Developer Explorer
LocalStudy provides a fully documented FastAPI serverless backend on Vercel:
GET / → Web Studio & Service Overview
GET /health → Health status ({"status": "healthy"})
GET /api/info → Service discovery and route catalog
GET /api/project/list → List all lecture projects
POST /api/project/create → Create a new structured lecture project
DELETE /api/project/{id} → Delete a project from database
POST /api/video/analyze → Extract video metadata & direct stream URLs
POST /api/video/direct-stream → Direct progressive CDN stream links
POST /api/pdf/generate → Serverless ReportLab PDF study guide compiler
POST /api/ai/summarize → AI Lecture Study Notes & questions generator
GET /api/transcript/{proj_id} → Fetch lecture transcript segments
POST /api/transcript/export → Export transcript to SRT, VTT, TXT, or JSON
GET /api/bookmark/list → Fetch pinned study bookmarks for project
POST /api/bookmark/create → Pin study bookmark with timestamp & notes
DELETE /api/bookmark/{id} → Delete a study bookmark
GET /api/system/info → Cloud runtime specs, hardware profile & cookies
GET /docs → Interactive Swagger UI documentation
GET /redoc → ReDoc API reference
